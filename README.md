# Banking-App
Command-Line Banking System

A Java-based banking application that simulates a simple banking system with SQL database integration. Supports CRUD operations, transaction history, and account management, designed to practice object-oriented programming and database connectivity.

Technologies Used

Java – Core application logic

SQL – Relational database for storing account data

JDBC – Java Database Connectivity for interacting with SQL

Object-Oriented Programming – Modular, reusable code

Features

Create, read, update, and delete bank accounts (CRUD operations)

Deposit and withdraw funds

Track transaction history for each account

Input validation and error handling to prevent invalid transactions

Secure database integration using JDBC
